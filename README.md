# Isla de Ideas

Generador de ideas de diseño con estilo de pueblito-isla. Cada vez que generas sale:

- el nombre de una marca inventada y su slogan
- la categoría o giro del negocio
- una estética (Frutiger Aero, Coquette, Dreamcore, Solarpunk y más)
- una paleta de colores sacada de imágenes al azar o de tus propias imágenes
- el encargo que hay que diseñar y un reto extra

Puedes fijar con el candado lo que te guste y volver a tirar lo demás.

## Tus imágenes

Con **Subir mis imágenes** agregas fotos que quedan como opciones del generador. Se guardan solo en tu navegador: nadie más las ve y no se suben a ningún servidor.

## Cómo usarla

Es un solo archivo, `index.html`. Ábrelo en el navegador o publícalo con GitHub Pages.
